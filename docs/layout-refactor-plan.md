## 0. 目标与验收

**目标**：每次全量布局一次通过，不出现意外错位与重叠；个别不合理处单独调整并把配置记录下来（APM 为先例）。

**验收（P3 演练）**：codes SVG 移出链路后从零全量重跑（rebuild10 → build-network → gen-codes-cards ×2 → sync-base → gen-quiz-data），与现验收态 diff，每条 diff 归入两类之一：
- (a) 已入表定制的预期差异（LABEL_POLICY / ANCHOR / OFFSETS 条目可解释）；
- (b) 未记录的隐式手工调整 → 逐条迁入配置表。

**终态可度量**：diff 集合全部落在 (a)，此后"重新布局一次性"= 可重复通过的机械事实。

## 1. 总纲：三参数模型 [定稿]

每类元素的位置统一为：

```
位置 = 锚点A(参照物 + 8方向) + 标准间隔G(查表) + 坐标偏移O(dx,dy)
```

- **A 固定** → 重布局不产生大变动；
- **G 全网同一张表** → 视觉一致性可审计；
- **O 只为消重叠存在**，每次微调留痕（谁、为什么、多少）。

| 元素 | 锚点 A | 标准间隔 G | 偏移 O |
|---|---|---|---|
| 站点圆点 | 走廊几何（rebuild10 CFG，真源，不参数化） | 圆径规则（单线 4.5 / 换乘大圆） | 无——几何即真值 |
| 站点/序号 | 圆=走廊钉位；胶囊=组心=钉质心 | 标准形 S/V/T/品/田 + 等隙 GAP、行距 H | 站级 dx,dy |
| 站名 | 标记外沿点 + 8方向（`DIRS`） | 环梯 RINGS_TIGHT + 净距 ST_GAP | 站级 dx,dy |
| 徽标 | codes 锚表(已有线,自锚) / 终点延长线方向(新线) | 牌高 13.5 + 净距梯 | 线级 dx,dy |

样板间：编号胶囊引擎（`layout_candidates()` 组心锚定 + 标准形 + 等隙半距）已经是本模型，其余三类拉齐到同一水位。

## 2. 锚定链 L1→L4（顺序铁律）[定稿]

```
L1 路线走廊(rebuild10 CFG, 真源, 永不让位)
 └→ L2 站点圆点 + 序号胶囊(锚=走廊钉位/钉质心)
     └→ L3 站名(锚=L2标记外沿点+8方向)
         └→ L4 徽标(锚=终点走廊延长线+文字三点一线)
```

三条铁律：

1. **锚定参照只准指向上游**：每层只把 L≤本层 的元素当锚点与障碍物，反向禁止。
2. **冲突让位方向固定**：重叠时锚定序靠前的层不动，靠后的层让。改哪层由层级决定，不由"哪个好改"决定。
3. **执行顺序 = L1→L4 单向流水**：层内怎么放（搜索/查表/自锚）自由，层间顺序不可错；层内冲突在本层内解决。

现状符合性（2026-10-28 实测）：
- `shift_station_chips` 是 L2 层内冲突（胶囊沿本线走廊推让本站圈环轮廓，推不动收缩内衬），未越层 ✓；
- codes 侧 `nudge_labels` 站名让胶囊（L3 让 L2）✓；
- 徽标各 pass 只吃障碍不被别人参照（L4 垫底）✓；
- 已知缺口：build-network 全新站名搜索未把序号胶囊当障碍（验收态靠 codes labels_inner 回填间接合规）——[待实施] `st_clear` 读 `_chip-rects.json` 补齐 L2→L3 闭环。

## 3. 分组契约（SVG 文档结构，与锚定链正交）[定稿]

### 3.1 现状实测（2026-10-28）

| 产物 | 分组（文档顺序 = z 序） |
|---|---|
| 底图 network-全网.svg | 走廊(298 line) → 站圆(302 circle) → 换乘标记 → 线路徽标 → 站名标注 → 图例 |
| codes network-全网.codes.svg | 走廊 → 线路徽标 → 站名标注 → 编号牌(400×2文字) → 图例 |

两问两答：
- **四类元素是否不同层级？是**——各自独立 `<g>`，两份一致（徽标组在文字组下、编号牌组最上）。
- **单条线元素是否同组？不是，且不应该是**——分组=类型轴，线路身份=属性轴（徽标 `data-term`、编号牌牌面解码、走廊色/线序；`data-line` 分组计数=0）。按线分组被禁止：①全局 z 序做不成（A 线文字夹进 B 线走廊绘制序）；②拼图按类型藏显（站名模式/线号模式）需要单选择器整组操作。

### 3.2 契约条文

1. **两个"层级"正交，互不推导、各自冻结**：
   - 锚定链（计算依赖）：L1→L2→L3→L4，管"谁参照谁、冲突谁让位"；
   - 绘制 z 序（文档结构）：走廊 < 站圆 < 换乘标记 < 徽标 < 站名 < 编号牌(codes)，由可读性定（编号牌属 L2 身份却压站名之上=有意设计）。
2. **组内绘序确定性**：走廊组内按 ORDER 线序发射（决定交叉点谁压谁，与"共线大忌"并列的视觉规则）；站名组内按放置序。现状已确定（重跑幂等证明），写死。
3. **图例组 = 静态版式**，不参与锚定链，位置为常量。
4. **禁止项**：按线重组分组；跨组移动元素身份（徽标永远住徽标组）；组外游离元素。
5. [待实施] **结构断言**：verify-all 检查两份 SVG 组集合与顺序（底图6组/codes5组）+ 组外无游离元素。

## 4. 分型体系 [定稿]

归型是**纯几何函数**：只读 L1/L2 几何，同一份 CFG 永远归出同一型；个别站归型不合意在元素 `data-loc` 钉型覆写（现 `TERM_DIR_EXEMPT` 即 T1 覆写雏形，P2 迁并为属性格式，字节不变）。

### 4.1 L2 站点标记三型（L3 锚点的几何输入）

| 型 | 判定 | 形态 | 现有对应 |
|---|---|---|---|
| M1 单圆 | 单线 | r=4.5 圆 | ✓ |
| M2 共圆 | 多线 spread≤SPREAD_CIRC | 换乘大圆 | ✓ |
| M3 换乘胶囊 | spread>SPREAD_CIRC 或 FORCE_CAPSULE | 凸包胶囊（镇龙=几何锁死豁免判例） | ✓ |

L2b 序号胶囊：锚=钉质心，标准形 S/V/P3/P3D/G4/H + 排布优先级（1骑线/2竖叠/3T字品字/4田字），已是标准形模型，原样保留。

### 4.2 L3 站名五型

| 型 | 判定（纯几何） | 锚点参照 | 摆位方案 | 现有对应 |
|---|---|---|---|---|
| T1 终点 | 本站是某线死端（度=1） | 死端段外向单位向量 | 走廊延长线上，gap 梯 5/9/14 | `term_dir` ✓ |
| T2 横/竖直线 | 邻段角度≈0°/90° | 标记外沿点+N/S 主向 | 紧环 ring[0]，净距 ST_GAP | 环搜 N 优先 ✓ |
| T3 斜线(45°) | 邻段角度≈45° | 标记外沿点+斜向法向(NE/NW/SE/SW) | 紧环 + **盒角对斜线净距口径**（徽标 `_place_ok` 角点检查同款，站名侧补） | 环搜隐式，无显式口径 |
| T4 多线交叉 | 标记 lines≥2 | 走廊交点/组心 | `card_label` 卡片方位优先 → 8向环梯兜底；归属歧义检查（标签中心离本站最近）保留 | `card_label`+`opt_n` ✓ |
| T5 密集组策略 | 命中组策略表 | 圆右缘+gap 贴线列 | 贴线+豁免走廊+白光环（APM 东带=唯一判例，不迁移不改名） | `LABEL_POLICY` ✓ |

候选顺序 = 型内优先、通用兜底：`_cands_for` 重构为分派器，先出本型专属候选，全拒落通用 8向环梯。字号梯（7.5/6.0/5.0/4.2，横排逐档缩小=用户定稿）保留，但档序入表（FONT_LADDER），顺带消灭"字号档×候选序倒置"隐患。

附属元素：**英文行 = L3 附属**，锚=中文主行（多行如广州南站随主行成组移动），无独立分型；move-label 连 EN 行同搬的现状语义不变。

### 4.3 L4 徽标四型

分型判据 = 焊接图分析（`line_ends` + `_weld` + 假终点过滤 `_on_seg_interior` 已算好）：连通分量数=段数，度=1 真端点数=终点数。

| 型 | 判定 | 枚数 | 锚定方案 | 现有对应 |
|---|---|---|---|---|
| B1 双终点(标准) | 真终点=2 | 2 | 每端：终点延长线方向+gap 梯，与 T1 文字三点一线 | 端点外推 ✓ |
| B2 环线(无终点) | 真终点=0 | 1 | 锚=环体本身，贴本体网格搜位（走廊净距硬门，搜索有下限步长） | 11号线 ✓ |
| B3 多终点(支线) | 真终点≥3 | 每终点 1 枚 | =B1 逐端复用，端间互为障碍；键=(线名,终点) 天然区分 | 3/14号线 ✓ |
| B4 多段 | 连通分量>1 | 每段 2 枚 | 先按分量切段，段内=B1，段间独立 | 12号线双段卡 ✓ |

- **枚数公式门禁** [待实施]：每线枚数=型公式，全网求和=41（金丝冻结值；11号线1+12号线4+3、14号线各3+其余各2）。布局期即红，不等 quiz 装载 fail-loud。
- 自锚定键原样兼容：B1/B3/B4=(线名,终点站名)；B2=线名单键特例。
- 每型一个方案，**方案内禁止发明变体**（骑交点/贴拐角类教训）；十八轮判死的 R1 梯度/R2 网格死代码（gen_network `continue` 之后约150行）与被 codes 锚覆盖的白算钳制，P1 清除。

## 5. 配置与记录地（custom_params.py / SVG data-）[定稿]

### 5.1 保留表（原样，零迁移）

`LABEL_POLICY`（=T5 判例，表头加注）、`LINE_DISPLAY`、`CHIP_FONT_OVERRIDE`、`FORCE_CAPSULE`、`TERM_DIR_EXEMPT`（P2 迁并为元素 `data-loc` 覆写后删除）。

### 5.2 参数记录地分工（2026-10-28 用户定稿）

| 参数层 | 记录地 | 理由 |
|---|---|---|
| **G 标准间隔** | custom_params.py `STANDARD_GAPS`（唯一汇总处） | 全网同一套数值，改一处全局生效 |
| **A 锚点**（型/方向/环档） | **SVG 元素 data- 属性** | 随元素走：sync/挪站自动携带；几何变动后重布局按语义对新圆心重推位 |
| **O 偏移**（dx,dy+事由） | **SVG 元素 data- 属性** | 与坐标终值同址，从结构上消灭"表-SVG 双真相漂移" |

ANCHOR/OFFSETS 独立表**取消**（独立表必与 SVG 漂移，需专门门禁看护；同址记录免此患）。custom_params 只保留**策略表**——作用于生成期、元素尚不存在时就要生效的组规则：`LABEL_POLICY` 五表原样。

**属性 schema**（每类元素一组，清单唯一声明于此）：

| 元素 | 属性 | 例 |
|---|---|---|
| 站名 text | `data-loc="型\|方向\|环档"`，可选 `data-nudge="dx,dy,事由"` | `data-loc="T2\|E\|0"` |
| 徽标 g | `data-anchor="方向:gap档"`（身份键仍为 data-term） | `data-anchor="NE:1"` |
| 编号牌组 | `data-shape="V"`（标准形覆写，缺省=按规则） | `data-shape="G4"` |

- **缺属性 = 未钉定**，引擎走分型候选——渐进采用，不要求一次性全网补齐；
- `data-pin-base` 戳机制不变（sync-base 认戳）；codes-final-pins.json 仍为链路间传递的派生物，语义源 = SVG data。

**语义锚的增益**：锚点从"裸坐标"升级为"语义"。现自锚只搬坐标——CFG 挪站后旧坐标全部作废、逐站手工重挪；记 `data-loc` 后重布局按方向+环档对新标记位置自动重推，几何变动不再废锚。这是"重新布局一次性"的最后一块拼图。

### 5.3 条文

1. **属性=层内钉位**：data- 属性永远不能表达跨层调整；跨层问题回上游层修。
2. **阈值成对声明**：同一物理间隙的引擎净距与门禁阈值（如走廊 6.5 / 角点 4.2）必须在 STANDARD_GAPS 同一条目成对出现，禁止单边出现；门禁阈值 ≥ 引擎净距。

### 5.4 写入契约（数据一致性，2026-10-28 用户令：不能多次写入丢参数）

事故档案（同类根因=正则局部手术 + 多写者互不知情）：16连 scale 整值替换丢徽标缩放、非自闭合 rect 正则漏匹配黑环落下（V5-5.60）、`548.6`≠`548.60` 字符串匹配静默失败。

1. **整元素替换**：任何写 SVG 的工具必须整元素（含全部子节点与属性）替换，禁止跨元素正则局部手术；
2. **属性 owner 唯一**：每属性一个写者（`data-loc`/`data-nudge`=move-*；`data-term`=生成器；`data-pin-base`=定制打戳方）；其余写者只继承、不清除；
3. **继承报告**：生成器重写整组时，上一版 data- 属性逐元素继承；继承不到的列报告，不静默丢；
4. **写后断言** [待实施]：每次写盘前后做属性清单 diff，变化集必须等于本次意图修改集；并入门禁 G4。

## 9. 收敛循环（异常处置 SOP）[定稿]

```
门禁红 / 渲染见重叠
  → 判定错在哪层(层级链)哪型(分型):
     锚点错   → move-* 调方向, 自动写入 ANCHOR + codes SVG
     间隔不适 → 该站/组加组策略条目(LABEL_POLICY 式)
     个别偏移 → move-* 微调留痕
  → sync-base → verify-station 秒级复验 → 汇报数字 → 用户确认提交
```

常用任务标准流程：
- **点名微调**：move-label/move-badge → sync-base → verify-station → 渲染+数字汇报（链路不变，P2 起工具同时写 data-loc/data-nudge 属性，SVG 单处记录）。
- **挪站**：单线卡改圆 → move-station-codes 同步 codes 家具 → build→gen×2→sync→gen-quiz-data → 全门禁（既有配方不变）。
- **新增一线**：CFG 入 rebuild10 → L4 自动分型（B1-B4）→ 枚数门禁自动校 → 全链一次通过。
