# 单线卡片制作指南（以 1 号线为样板）

## ⚠️ 四条铁律

1. **站名/徽标不与地铁线/标识重叠** — 标签放置前检查与走廊线段、其他标签包围盒、徽标矩形的碰撞；有碰撞换方位重试；终点站徽标放终点圆外不压站名
2. **斜方向文字对齐** — 竖线段(|dx|远大于|dy|)左右放(中心y=圆心y)；横线段上下放(中心x=圆心x)；**斜线段(|dx|≈|dy|)按纵向处理→左右放**；拐角站最后放、四方位按到已放标签最远选
3. **站点圆点严格在地铁路线上** — 非拐角站投影吸附(<1.5px)；拐角站保留原图圆位；终点圆在线段端点外→延伸线段到圆心
4. **地铁路线不中断、不多出** — 所有走廊段全连通(端点间隙<3px)；无超出终点圆外的游段；终点圆外走廊删或截断到圆心

### 四项硬校验脚本(每次改图后运行, 全✓才交付)

```python
import xml.etree.ElementTree as ET, json, math
NS = 'http://www.w3.org/2000/svg'
r = ET.parse('assets/lines/line-X号线.svg').getroot()  # 换线改文件名
mp = json.load(open('data/_l2circles24.json'))  # 换线改文件名

segs = [(float(l.get('x1')), float(l.get('y1')), float(l.get('x2')), float(l.get('y2')))
        for g in r.iter('{%s}g' % NS) if g.get('id') == '走廊' for l in g]

def sd(s, cx, cy):
    x1, y1, x2, y2 = s
    dx, dy = x2 - x1, y2 - y1
    L2 = dx * dx + dy * dy
    if L2 < 1e-6:
        return math.hypot(x1 - cx, y1 - cy)
    t = max(0, min(1, ((cx - x1) * dx + (cy - y1) * dy) / L2))
    return math.hypot(x1 + t * dx - cx, y1 + t * dy - cy)

# 铁律 3：圆在线上
w = max(min(sd(s, cx, cy) for s in segs) for cx, cy in mp.values())
print('铁律3 圆在线: %.1fpx %s' % (w, '✓' if w < 1.5 else '✗'))

# 铁律 4a：走廊连通
from collections import defaultdict
adj = defaultdict(set)
for i in range(len(segs)):
    for j in range(i + 1, len(segs)):
        for ex, ey in [(segs[i][0], segs[i][1]), (segs[i][2], segs[i][3])]:
            for fx, fy in [(segs[j][0], segs[j][1]), (segs[j][2], segs[j][3])]:
                if math.hypot(ex - fx, ey - fy) < 3:
                    adj[i].add(j)
                    adj[j].add(i)
vis = {0}
st = [0]
while st:
    u = st.pop()
    for v in adj[u]:
        if v not in vis:
            vis.add(v)
            st.append(v)
print('铁律4a 连通: %d/%d %s' % (len(vis), len(segs), '✓' if len(vis) == len(segs) else '✗'))

# 铁律 4b：无游段
ext = [(si, e) for si, s in enumerate(segs) for e in [(s[0], s[1]), (s[2], s[3])]
       if min(math.hypot(e[0] - cx, e[1] - cy) for cx, cy in mp.values()) > 50]
print('铁律4b 无游段: %s' % ('✓' if not ext else '✗ %s' % ext))

# 铁律 1：标签避线避徽标
lbls = {t.text: (float(t.get('x')), float(t.get('y'))) for t in r.iter('{%s}text' % NS)
        if t.text and not all(ord(c) < 128 for c in t.text)}
ov = [nm for nm, (lx, ly) in lbls.items() if nm in mp and min(sd(s, lx, ly) for s in segs) < 5]
print('铁律1 标签避线: %s' % ('✓' if not ov else '✗ %s' % ov))

# 铁律 2：对齐检查(左右放的站中心y=圆心y, 上下放的站中心x=圆心x)
# 视觉验收补充：截取渲染图逐站比对
```

## 一、总体架构

一张单线卡片 = **走廊矢量 + 站圆 + 官方徽标 + 结构化站名文本**，四层分离、各自确定性生成：

| 层 | 来源 | 工具 |
|---|---|---|
| 走廊（线路路径） | 原 SVG 中该线 CSS 色类的全部 stroke 元素 | `tools/line-card.py` |
| 站圆（站台圆点） | 原图同色环带站圆 + 锚点播种 + 漏检合成 | `tools/line-card.py` |
| 徽标（线路标识） | 参考官方图布局，纯矢量绘制 | `tools/l1-badge.py`（参数化线号/线色） |
| 站名（中+英） | **不拷字形碎片，直接 `<text>`**（数据在 metro-known） | `tools/l1-auto-labels.py` |

## 二、核心教训（先读这个，避免重蹈覆辙）

1. **原 SVG 文字全是转曲轮廓**（Illustrator 文字转曲，非 `<text>`）。一切"捡字形碎片"的方案（按颜色/位置/聚类归属）在密集换乘区必然东缺西缺——**唯一正道是站名用结构化数据 + `<text>` 渲染**。
2. **拐角站圆不能机械投影**：长寿路在横竖交界，投影到斜段中点会"歪"。拐角站用原图圆位（原图把它放拐角内侧），非拐角站才投影吸附到走廊线。
3. **标签对齐/间隔的基准必须是"圆心"和"走廊实测净距"**，不能用锚点投影（拐角站投影点偏离圆心，间隔会量错）。
4. **pymupdf 不渲染 `<line>` 的 CSS 描边**（黄走廊全丢）→ 一切栅格验证必须走**浏览器截图 + 像素计数**；视觉工具会幻觉，只作辅助。
5. **path d 是绝对/相对命令混合**，正则抽数字算坐标全错——必须用状态机 `sample_d()` 解析。
6. 每次交付前**自查裁剪图**（渲染后逐站/逐元素裁剪核对），不要等用户提醒。

## 三、分步流程

### 1. 走廊提取
- 解析原 SVG `<style>` 得 CSS 类→线色映射（如 st52=#FDD835 是 1 号线黄）。
- 该色类的全部 `line`/`path` 元素（含祖先链、嵌 CSS）拷入卡片，viewBox 沿用原图坐标。
- `<line>` 元素几何必须进采样（走廊主体常是 line 段，只采 path 会漏）；采样时沿线 10px 插值。

### 2. 站圆
- **颜色法**：原图渲染图上站圆环带采色，与线色匹配（<60）归该线。
- **几何兜底**：圆心距走廊采样点 <17px 的圆收入（换乘站环带被他线色污染时靠这个）。
- **锚点播种**：svg2off 锚站（走廊 15px 内）强制收录就近圆；原图无圆的（西塱/芳村/广州东站这类终点/特殊站）按站样式**合成**（r=4.5 白底线色描边）。
- **吸附**：非拐角站圆投影到走廊折线（最大偏差应 <0.1px）；**拐角站**（圆心 25px 内有走廊顶点且两侧方向混合）保留原图位置。
- **数量校验**：删到正好 N 站 N 圆，全部距锚点 ≤15px。

### 3. 官方徽标（三枚）
布局按官方参考图像素测量（参考网格 107×59 → SVG 80×43，圆角 9）：
- 黄底胶囊 80×43 rx9，线色填充；
- 数字「1」：font 25 bold，baseline y+32.5，**像素级上下居中**（渲染截图量上/下留白差 ≤2px）；
- 右列顶部与「1」顶部对齐：「号线」baseline y+22（font 11）在上，「Line 1」baseline y+35（font 7.5）在下，行距收紧；
- 「1」右缘与右列水平间距 ~12；
- 三枚位置：**左上角全尺寸** + **两终点各一枚 60% 缩放**，终点徽标沿延长线放且**避开站名标签**（先放标签再放徽标，或反向检查重叠）；
- 其他线复用：换 fill 线色、数字、'Line N' 即可（`tools/l1-badge.py` 参数化）。

### 4. 站名自动放置（六规则算法）
`tools/l1-auto-labels.py`（v2 干净版），输入=卡片圆心 + 走廊折线 + 站名数据：

1. **方向判定**：每站取最近走廊线段方向 → 横向线上下放、竖向线左右放；
2. **终点中轴对齐**：横向终点文字在端点外侧、垂直中心共线（端左/端右）；竖向终点上/下方、中心 x 共线；
3. **不交叉不重叠**：线段-矩形相交检测（CCW 法，自站 ±12px 豁免）+ 标签互斥 + 其他站圆覆盖检测，冲突翻面/换候选；
4. **盒中心对圆心**：上下放→中心 x=圆 x；左右放→中心 y=圆 y（**以圆心为准，绝不重投影**）；
5. **净距统一 G=10**：候选盒生成后量到走廊折线的实际净距，不足沿法向外推（`push_to_gap`），中轴锁定圆心；
6. **拐角站两遍放置**：非拐角站先放；拐角站（顶点 25px 内、方向混合）最后放，四方位按"到已放标签的最小距离"降序选（长寿路因此从"上"改"左"，避开陈家祠）。

字宽用 PIL 实测（msyh 2x 后除 2），块 = 中文行 11 + 间隙 1.5 + 英文行 6。
1 号线实测结果：16 站零交叉零重叠，净距全部 10.0-10.2。

### 5. 验收门（程序化，逐站）
- 站圆：全部距锚点 ≤15px、数量=N；
- 站名：每站 `<text>` 存在且非空（结构化，不会缺字）；
- 布局：自检输出 交叉=0 重叠=0 净距 min≈G；
- 渲染：定尺寸包装页（img 固定 1466 宽，letterbox 公式映射）浏览器截图，逐站裁剪 + 深色像素计数（注意文字抗锯齿用 <200 阈值；两字小站墨量 165-300 属正常，阈值按字数缩放）；
- 16 格对照表存档（`assets/_l1-*.png` 系列）。

## 五、其他线复用时的差异点

- **线色/类名**：从原 SVG CSS 找该线色类（如 8号线 st?），走廊提取换类名；
- **站表**：L1 列表换成该线站序（metro-known），锚点用 svg2off-anchors 中该线的（覆盖不足时需补锚点：办法=官图胶囊中心人工确认，或用已验证邻线站推算）；
- **拐角/终点**：算法自动检测，无需手标；
- **平行线/共线段**（如 1/8 在老城区并行）：走廊可能重叠，站圆归属靠颜色+锚点双保险；标签互斥规则会自动错开；
- **F1/F2/F3 佛山线**：metro-known 无数据，需先补站表（来源另找）再走同流程。


## 六、2号线追加教训（v3 修正，2026-10-19）

1. **换乘枢纽的圆不止一个**：同一站位有多个线属圆（如嘉禾望岗 2/14 双圆、广州南站多线圆、白云公园双标记），且部分圆在 2 号线走廊延长线上（(1422,1586) 其实是 7/22 的圆）。**弧长序 + 前后缀对齐会把整段错一位**——必须用"原图放大读标签"抽查至少拐点前后各两站，锚点（公园前）只钉得住一侧。
2. **走廊段要全量提取**：带 inbox 过滤会漏段（北端 NE 对角线被旧 viewBox 裁掉），漏段导致圆缺失→错位连锁。提取后核对：站数 = 圆数 + 合成数，逐段间距均匀性（相邻圆距突增 >1.6×中位数 = 中间缺站或混入他线圆）。
3. **终点裁剪**：走廊在两终点圆外会出头（绘制余量），组装时按 `near_pt<12` 的段在终点圆处 clip。终点圆取"沿走廊方向最远那个"，不是离锚点最近的。
4. **换乘胶囊站**（广州火车站/三元里）：原图无独立 circle（画的是换乘大标记），合成圆放走廊插值位。
5. **viewBox 边距**：左边距 85（英文站名比中文宽，防出框）；竖线（2号线是竖长条）验收页按真实宽高比设 img 尺寸。
6. **弧长链构建**：走廊点最近邻行走必须从端点起步（按 y 排序取最值），文档序起步会乱序。

### 规则 7（2号线补充）：对角线段标签法向放置
最近走廊段两轴分量均>0.45的站(斜线段)，标签放"沿线的法线两侧"而非上下：
盒中心 = 圆心 + 法线单位向量 × (G + 盒在法向的半投影)；外推也只沿法线。
否则坐标轴向外推在对角线上=沿线滑动，标签会漂到邻站(南洲漂到东晓南侧33px的根因)。
1号线无此问题(全线正交)。竖版卡片验收页按真实宽高比设 img 尺寸。

### 规则 8：斜线密集段垂向(法线)放置 —— 数学上唯一无歧义方案
40px站距+45°斜线下, 轴向放置(上下/左右)的标签中心到邻圆距离恒<=到自圆(实测29-43px互咬), 必错位。
垂向放置: 标签中心=圆心+法线方向d, d=G+(|nx|·bw+|ny|·bh)/2, 优先线左侧(nx<0); 零沿线分量 → 自圆必最近(程序可证)。
验收必跑"就近归属测试"(全站标签中心到全部圆最近者必须是自圆)。规则7旧版(法右/法左双向搜索)废弃。
另: 改标签脚本必须只清 g[id=站名标注], 全删<text>会把徽标文字一起删掉(空蓝框bug根因)。
