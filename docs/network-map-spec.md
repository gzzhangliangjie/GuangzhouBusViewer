## 一、换乘枢纽标记（单圆 vs 胶囊）

### 能并圆 → 共享圆
两线走廊有共同可达点且各线钉距 ≤ 9px → 合并为一个 r=5 多线黑描边共享圆。
钉位微调只沿各自走廊（走链单调不折返），跨度压到最小即可。

### 并不了圆 → 定向胶囊（核心新规范）

**胶囊方向 ⊥ 线群走向**：

| 线群主要走向 | 胶囊方向 | 钉位排列 | 实例 |
|---|---|---|---|
| 纵向（竖线群） | 横向 | 各线钉同 y 横排 | 西塱、芳村、广州南站、官洲、大学城北、大学城南 |
| 横向（横线群） | 纵向 | 各线钉同 x 纵排 | 东湖、沙园、番禺广场、广州火车站、五羊邨、嘉禾望岗、广州东站 |
| 45° 斜线 | 斜向（⊥斜线） | 两钉连线 ⊥ 斜线 | 镇龙、中山八 |

钉距 > 9px 即成胶囊，**尽量小**；需更小时可重切走廊缓坡让两线端互探（东湖接缝压缩 27→13.5px 先例）；走廊几何锁死的（芳村两竖线相距 18px）以走廊几何为下限。

两点 hull → line 双描边（14 黑外 + 10 白内）；多点 hull → poly 路径（曾 4 黑被 6 白全盖隐形，已修为 14/10 同口径）。

`FORCE_CAPSULE` 字典：几何锁死站（钉距 ≤ 9 仍需胶囊）的显式豁免。

## 二、站名标注

### 统一引擎
全部站名 7.5px / weight=700 / middle 锚，换乘站与普通站大小间距一致。

### 放置候选序
1. 终点站：走廊延长线上（圆心 + 走廊方向 × (r + gap + 盒半伸长)，含斜线）
2. 卡片标准方位拉近（钳制 13px，保盒边净距 ≥ 3px 外推）
3. 紧环 4/8/13/19 八向
4. 逐档缩小重试：6 / 5 / 4.2px（2026-10-22 用户：有重叠字就小点）
5. 放不下 → 不放（不搞缩放层/LOD 等骚操作——缩放是等比放大不产生空间）

### 硬校验
- 本站标记盒边净距 ≥ 3px（不贴不叠）
- 归属无歧义：标签中心必须离本站标记最近（中医药大学标签曾落本站与邻站正中间）
- 基线偏移 = 盒中心 + 0.8 × 字号（算错会使字形下溢贴圆）

### 密集区横排（竖排已废）
竖排堆叠 2026-10-22 被用户否决（"竖向显示非常诡异"）→ **一律横排**。三平行竖线夹缝（APM 中段，竖线间距 20-27px）横排放不下时：
- 放竖线外侧专用列（APM=东带列 1695 起），**允许稍微压走廊**（用户定稿："稍微重叠一点也可以接受"），渲染配白描边光环（paint-order:stroke, #FFF, 2.2px）保压线可读；
- 字号 6px → 5px 逐档缩小；y 向 ±9px 偏移候选错开邻站歧义（妇儿中心 vs 冼村隔 29px 先例）；
- 其余检查（本站净距/归属歧义/标签互斥/撞站圆）全部保留，只豁免走廊碰撞。

## 三、线路徽标

### 定位公式（唯一规则）
```
徽标中心 = 终点圆心 + 走廊方向 × (r₀ + gap + 徽标半伸长)
```
- r₀ = 圆半径（普通站 4.5 / 胶囊半宽 7）
- gap 梯度：7 / 12 / 20 / 32 / 50 / 72 / 100px
- 徽标半伸长 = (宽×|dx| + 高×|dy|) / 2（沿走廊方向的投影半长）
- **不依赖文字位置**：文字能上延长线 → 三点一线完美；文字被挤开 → 徽标仍在正确位（"文字放不了不代表徽标放不了"）
- 徽标有底色**可盖走廊**（`ignore_corridor=True`），不查撞走廊；仅查撞徽标/撞标签/撞站圆
- 仅本终点被其他徽标占时试另一终点

### 斜线终点：相对文字居中（2026-10-22 用户定稿）
45° 斜线终点（5/13/14 号线）**不走上式斜推**——徽标沿延长线斜推会与文字对角错位。规则：
```
徽标 = 终点标签正上方或正下方，同 x 居中
方向 = 延长线走向：斜向上 → 正上方；斜向下 → 正下方
距离 = 文字盒半高 + gap(7/12/20) + 徽标半高
```
碰撞检查不豁免走廊（居中位不得压任何线；全拒时回退延长线公式）。

### 环线徽标（11 号线）
环线无终点，终点公式会落到任意节点旁压线。规则：跳过终点公式，**贴本体网格全域搜**（全线走廊 bbox，6px 步长，距本线走廊 6.5~60px 且不撞任何走廊/站圆/标签/徽标的最近合法位）。环线旁空位充足（华景路、赤沙—龙潭段均可），网格自然选中。

### 大小
全局 0.7 缩放（80×43 → 56×30），`BADGE_SCALE_BY` 单线再缩（APM 0.5 → 51×22）。

## 四、大坑档案（勿重蹈）

### rect_seg_dist 贯穿盲区
旧版仅"两端点都在矩形内"判相交——线段**穿过**矩形（两端在外中间横穿）返回正值，贯穿走廊的徽标位被放行（2 号线徽标被 22 号线红斜线贯穿，像素实锤 ~1800 红色 px/侧）。修 = slab 裁剪（Liang-Barsky）精确判交 + 单端在内也判 0。

### 多边形胶囊描边隐形
4px 黑描边被 6px 白描边全盖 → 描边永远不可见。修 = 14 黑 / 10 白双描边与两点胶囊同口径。

### 站圆可能是 path 不是 circle
花围圆 = st80 类 path（M 四段弧，菱形四点解出圆心恰在线上）——`<circle>` 元素扫描两轮全空差点误判"无圆"。扫站圆必须 circle + path（M 锚点法）双路；path 的 d 数字配对 bbox 会被弧线参数污染成负值垃圾。

### 站名↔圆位配对错位
圆位吻合 ≠ 配对正确：只对了圆坐标没对名 ↔ 圆（10 号线西段 4 站配错）。无 text 层的 SVG 站名配对存疑时一律 ref.jpg vision 实读 + 站序联立。

### CFG 行尾注释吞钉
Edit 追加 `#注释`时把匹配前缀后的同行钉位全吞进注释 → 插值兜底自洽照样 18/18 全绿（门禁只查内部一致不查真值），全网计数异常才露馅。铁律：① 多钉一行加注释先拆行；② rebuild 后看"覆盖 N 站"清单数量。

### 同名多线钉编辑改错对象
21 号线与 14 号线的镇龙钉同坐标同站名，Edit 按注释文本匹配改到了 14 号线那条——同名多线钉编辑必须先 grep 确认行号归属。

### 贴本体校正与终点策略打架
终点徽标本就应在走廊延长线远端（离本线走廊 > 90px 是常态），被"贴本体"网格搬到 mid-line。修 = 终点 120px 内不迁。

### ignore_corridor 改变行为域后删锚
加 `ignore_corridor` 后引擎行为域改变 → 删除手动锚让引擎"自动放" → 所有用户验收过的终稿位全部被覆盖到不同位置。**用户验收过的锚 = 终稿，绝不允许引擎覆盖**。

### 旧管线 connector 碎屑画法
1 号线长寿路圆画在线外 3.15px + 7px connector 碎屑段（两份，一位/两位小数格式各一）——碎屑即 G16 存量红根因；正解 = 圆上拐点 + 删碎屑。

## 六、站点编号牌变体（*.codes.svg，十八轮定稿）

线路图页「查看站点编号」复选框（默认不勾选）勾选后加载 `*.codes.svg`：站圆与换乘标记替换为「线路|编号」编号牌。代码入口 `tools/gen-codes-cards.py`，门禁 `tools/verify-codes-cards.py`（V1-V7，140/140）。

### 6.0 通用原则
- **用户验收过的元件 = 终稿，引擎不得覆盖**（底图徽标位/密集档文字位均属此类）。改动已定元件必须先汇报清单经确认。
- 所有决策都在规则内优选；规则外的特殊定制（按线名/站名的硬编码表）一律禁止。
- **路线避让=通用规则，所有元件遵守**：任何元件（牌/标签/徽标）不得压走廊描边（标签量边、牌不盖他线、徽标不叠线）。唯一豁免=底图规范明示（徽标终点延长线可盖本线、密集档文字可压线）。
- **规则不完善→完善规则推导正确位置，不得回退绕过**（底图位是规则已正确工作的证据，不是免死金牌）。
- **单点修复不跑全量流程**：直接改SVG坐标→渲染验证→提交。
- 净距一律量到**描边边缘**（走廊±3.5、牌边框、光环外缘），不量中心线；几何函数矩形下标必须自检（_gap 曾把宽写成高）。
- 间距两级：**最小间距=1pt 硬底线**（贴着也算违规）＋**标准间距=8pt 软目标**（能标准就标准，不行就挤）。
- 走廊段筛选必须精确距离判定（中点±N 预筛会漏长线段）。
- 基卡重生成后必须重跑 gen-codes-cards.py（codes 变体从基卡后处理派生）。

### 6.1 数据（路线×编号真源）
- 双源：`data/station-codes-official.csv`（渲染输入）↔ `data/station-codes-master.json`（权威总表，320站/402码）。`cross_check_master` 门禁先行：D1 防编造 / D2 防漏采，当前 402/402 对齐。
- 站名归一 `norm_name`：原名优先，東→东（繁简）+去尾「站」兜底。
- 总表口径：「01-1」=官方支线编号；缺号=未开通（广州火车站@11号线暂缓开通，无牌保留原圆，勿补录）。
- 显示线号=裸线号（1/10/22/APM），广佛线=GF（用户指定）；序号两位补零；图上无走廊的线（佛山2号线）不生成。

### 6.2 路线（走廊/走向）
- 走廊几何=底图原样复制，编码版不改走廊。
- 走廊走向信号：`exit_vec`（站邻域走廊采样合成向量，**半径必须60**——30 采不到 38pt 外走向段）＝终点朝向/线路出向判据。
- 牌必须**触线**：每牌与本线走廊描边距离≤0（牌骑线，398/398 零失败）；牌不得盖他线走廊（晓港案：沿本线切向/垂直避开）。

### 6.3 文字（站名标签）
- 常规档 7.5px：走廊描边外净距≥1.0（量边不量心），先避让→对齐组心→四方位槽贴边（2pt 居中，斜角跨骑强制归槽）→16 方位扫描兜底（含自牌约束）。
- 密集档（底图 6px+白光环）＝**原位铁律**：底图位即终稿不挪（只有压牌才推离），压线豁免；降档统一规则：7.5px 实在放不下（违规或离牌>12pt）才降 6px+光环，无按线分支。
- 标签-标签净距≥1.5；贴站优先级最高（V7 门禁：组盒口径 ≤9pt）。
- 量法陷阱：只量 zh 盒会把带英文行的标签误报（英文行贴牌 2pt 填补间隙）；光环样式也是"统一大小"的一部分。

### 6.4 徽标
- **延长线规则本身含居中**（横向终点=横向延长线+垂直轴居中于走廊；纵向反之；斜线=终点标签同x上下居中）——全部由底图位承载，编码版**不得重排**。
- 仅两类改动：①真碰撞（gap<1pt）最小挤让；②用户逐枚确认的歧义重放（{'1','2','10'}：歧义=到他线走廊描边近于到本线边；重放=贴本体网格，终点邻段采样、不压他线描边、离他线≥20px 软偏好 4×、终点距离 2×）。
- **⚠️徽标必须靠近本线站点/走廊**（十八轮末 用户怒斥"有没有靠近APM线的站点"——徽标放在前不着村后不着店的空地=无法辨认归属）。环线徽标位置由规范指明（华景路/赤沙—龙潭段），不得做纯几何搜索选位。
- 历史教训：推力/滑位/批量重排/点名钉位/全量居中 pass/走廊轴居中/终点公式全档推远 全部被否。

### 6.5 站点序号牌
- 尺寸：全网 5.5px/高9，单线卡 6.0px/高10；全部牌**等宽**（APM/支线序号靠小字号+textLength 压入标准格，不因内容加宽）。
- 竖线位置自适应：1位数字线号格=文本+1.9（窄格）；APM 竖线右移（线号格=牌宽−边距−分隔−两位小字序号格）；2位/GF=定宽格。
- 数字纵向居中=central 基准+ty=cy−0.02fs（墨迹标定，改偏移必须 20x 渲染标定）。
- 排布=标准几何（组心恒=钉质心锚定）：1线=骑线单牌；2线=V上下叠；3线=T字/品字（行内等隙、行距恒定、单牌槽正对牌对中心）；4线=田字。线→槽=全排列搜索（全触线>规范优先级>方向匹配：钉偏移+走廊出向+线号tie-break）。
- 跨站碰撞解析须整组平移（保行对齐）；集中 review=`layout_violations` 须零。

### 6.6 站点圆圈和胶囊（换乘标记包络）
- 多线组外描边圈=沿胶囊边缘的双描边包络（黑 2×(pad+0.7)+白 2×pad 融合连续轮廓，pad=1.2 贴紧；发射序=黑pass→白pass→牌）。
- 外圈冲突：先沿走廊推让邻站单牌（整组平移保形）→逐档收缩 pad（0.9/0.6/0.4）。
- 暂缓开通站（广州火车站@11号线）保留底图圆点不画牌。

### 6.7 门禁总表
- 生成器内置：G1/G2 牌数=（站,线）∩（钉,码）；G3 触线 0 失败；G4 跨站牌零叠；G5 幂等；csv_vs_master 数据对齐；layout_violations=0。
- verify-codes-cards.py（Edge 渲染像素判定，140/140）：V1 牌数 / V2 边框线色 / V3 内部黑字 / V4 文本适配牌宽 / V5 牌不压站名 / V6 数字纵向居中（20x 精测） / V7 标签贴站≤9pt。
