## 一、换乘枢纽标记（单圆 vs 胶囊）

### 能并圆 → 共享圆
两线走廊有共同可达点且各线钉距 ≤ 9px → 合并为一个 r=5 多线黑描边共享圆。
钉位微调只沿各自走廊（走链单调不折返），跨度压到最小即可。

### 并不了圆 → 定向胶囊（核心新规范）

**胶囊方向 ⊥ 线群走向**：

| 线群主要走向 | 胶囊方向 | 钉位排列 | 实例 |
|---|---|---|---|
| 纵向（竖线群） | 横向 | 各线钉同 y 横排 | 西塱、芳村、广州南站、官洲、大学城北、大学城南 |
| 横向（横线群） | 纵向 | 各线钉同 x 纵排 | 东湖、沙园、番禺广场、广州火车站、五羊邨、嘉禾望岗、广州东站 |
| 45° 斜线 | 斜向（⊥斜线） | 两钉连线 ⊥ 斜线 | 镇龙、中山八 |

钉距 > 9px 即成胶囊，**尽量小**；需更小时可重切走廊缓坡让两线端互探（东湖接缝压缩 27→13.5px 先例）；走廊几何锁死的（芳村两竖线相距 18px）以走廊几何为下限。

两点 hull → line 双描边（14 黑外 + 10 白内）；多点 hull → poly 路径（曾 4 黑被 6 白全盖隐形，已修为 14/10 同口径）。

`FORCE_CAPSULE` 字典：几何锁死站（钉距 ≤ 9 仍需胶囊）的显式豁免。

## 二、站名标注

### 统一引擎
全部站名 7.5px / weight=700 / middle 锚，换乘站与普通站大小间距一致。

### 放置候选序
1. 终点站：走廊延长线上（圆心 + 走廊方向 × (r + gap + 盒半伸长)，含斜线）
2. 卡片标准方位拉近（钳制 13px，保盒边净距 ≥ 3px 外推）
3. 紧环 4/8/13/19 八向
4. 逐档缩小重试：6 / 5 / 4.2px（2026-10-22 用户：有重叠字就小点）
5. 放不下 → 不放（不搞缩放层/LOD 等骚操作——缩放是等比放大不产生空间）

### 硬校验
- 本站标记盒边净距 ≥ 3px（不贴不叠）
- 归属无歧义：标签中心必须离本站标记最近（中医药大学标签曾落本站与邻站正中间）
- 基线偏移 = 盒中心 + 0.8 × 字号（算错会使字形下溢贴圆）

### 密集区横排（竖排已废）
竖排堆叠 2026-10-22 被用户否决（"竖向显示非常诡异"）→ **一律横排**。三平行竖线夹缝（APM 中段，竖线间距 20-27px）横排放不下时：
- 放竖线外侧专用列（APM=东带列 1695 起），**允许稍微压走廊**（用户定稿："稍微重叠一点也可以接受"），渲染配白描边光环（paint-order:stroke, #FFF, 2.2px）保压线可读；
- 字号 6px → 5px 逐档缩小；y 向 ±9px 偏移候选错开邻站歧义（妇儿中心 vs 冼村隔 29px 先例）；
- 其余检查（本站净距/归属歧义/标签互斥/撞站圆）全部保留，只豁免走廊碰撞。

## 三、线路徽标

### 定位公式（唯一规则）
```
徽标中心 = 终点圆心 + 走廊方向 × (r₀ + gap + 徽标半伸长)
```
- r₀ = 圆半径（普通站 4.5 / 胶囊半宽 7）
- gap 梯度：7 / 12 / 20 / 32 / 50 / 72 / 100px
- 徽标半伸长 = (宽×|dx| + 高×|dy|) / 2（沿走廊方向的投影半长）
- **不依赖文字位置**：文字能上延长线 → 三点一线完美；文字被挤开 → 徽标仍在正确位（"文字放不了不代表徽标放不了"）
- 徽标有底色**可盖走廊**（`ignore_corridor=True`），不查撞走廊；仅查撞徽标/撞标签/撞站圆
- 仅本终点被其他徽标占时试另一终点

### 斜线终点：相对文字居中（2026-10-22 用户定稿）
45° 斜线终点（5/13/14 号线）**不走上式斜推**——徽标沿延长线斜推会与文字对角错位。规则：
```
徽标 = 终点标签正上方或正下方，同 x 居中
方向 = 延长线走向：斜向上 → 正上方；斜向下 → 正下方
距离 = 文字盒半高 + gap(7/12/20) + 徽标半高
```
碰撞检查不豁免走廊（居中位不得压任何线；全拒时回退延长线公式）。

### 环线徽标（11 号线）
环线无终点，终点公式会落到任意节点旁压线。规则：跳过终点公式，**贴本体网格全域搜**（全线走廊 bbox，6px 步长，距本线走廊 6.5~60px 且不撞任何走廊/站圆/标签/徽标的最近合法位）。环线旁空位充足（华景路、赤沙—龙潭段均可），网格自然选中。

### 大小
全局 0.7 缩放（80×43 → 56×30），`BADGE_SCALE_BY` 单线再缩（APM 0.5 → 51×22）。

## 四、大坑档案（勿重蹈）

### rect_seg_dist 贯穿盲区
旧版仅"两端点都在矩形内"判相交——线段**穿过**矩形（两端在外中间横穿）返回正值，贯穿走廊的徽标位被放行（2 号线徽标被 22 号线红斜线贯穿，像素实锤 ~1800 红色 px/侧）。修 = slab 裁剪（Liang-Barsky）精确判交 + 单端在内也判 0。

### 多边形胶囊描边隐形
4px 黑描边被 6px 白描边全盖 → 描边永远不可见。修 = 14 黑 / 10 白双描边与两点胶囊同口径。

### 站圆可能是 path 不是 circle
花围圆 = st80 类 path（M 四段弧，菱形四点解出圆心恰在线上）——`<circle>` 元素扫描两轮全空差点误判"无圆"。扫站圆必须 circle + path（M 锚点法）双路；path 的 d 数字配对 bbox 会被弧线参数污染成负值垃圾。

### 站名↔圆位配对错位
圆位吻合 ≠ 配对正确：只对了圆坐标没对名 ↔ 圆（10 号线西段 4 站配错）。无 text 层的 SVG 站名配对存疑时一律 ref.jpg vision 实读 + 站序联立。

### CFG 行尾注释吞钉
Edit 追加 `#注释`时把匹配前缀后的同行钉位全吞进注释 → 插值兜底自洽照样 18/18 全绿（门禁只查内部一致不查真值），全网计数异常才露馅。铁律：① 多钉一行加注释先拆行；② rebuild 后看"覆盖 N 站"清单数量。

### 同名多线钉编辑改错对象
21 号线与 14 号线的镇龙钉同坐标同站名，Edit 按注释文本匹配改到了 14 号线那条——同名多线钉编辑必须先 grep 确认行号归属。

### 贴本体校正与终点策略打架
终点徽标本就应在走廊延长线远端（离本线走廊 > 90px 是常态），被"贴本体"网格搬到 mid-line。修 = 终点 120px 内不迁。

### ignore_corridor 改变行为域后删锚
加 `ignore_corridor` 后引擎行为域改变 → 删除手动锚让引擎"自动放" → 所有用户验收过的终稿位全部被覆盖到不同位置。**用户验收过的锚 = 终稿，绝不允许引擎覆盖**。

### 旧管线 connector 碎屑画法
1 号线长寿路圆画在线外 3.15px + 7px connector 碎屑段（两份，一位/两位小数格式各一）——碎屑即 G16 存量红根因；正解 = 圆上拐点 + 删碎屑。

## 六、站点编号牌变体（*.codes.svg，2026-10-23 定稿）

线路图页「查看站点编号」复选框（默认不勾选）勾选后加载 `*.codes.svg`：站圆与换乘标记替换为「线路|编号」编号牌。代码入口 `tools/gen-codes-cards.py`，门禁 `tools/verify-codes-cards.py`（V1-V4，80/80）。

### 数据真源与核对门禁（2026-10-23 固化）
- 双源：`data/station-codes-official.csv`（渲染输入）↔ `data/station-codes-master.json`（权威总表，用户整理、与《广州地铁车站编号总表.pdf》同源，320站/402码）。
- **cross_check_master 门禁先行**：CSV 每行须在总表同编号（D1 防编造），总表每条（图上线内）须在 CSV 同编号（D2 防漏采），当前 402/402 全对齐；违例写 `report['csv_vs_master']`。
- 站名归一 `norm_name`：**東→东（繁简）**+去尾「站」兜底——CSV「東圃站」曾因繁体漏牌（5号线|19）；原名优先（广州南站 等「站」尾真名不剥）。
- 总表口径注记：「01-1」型=官方支线编号；**缺号=该区段尚未开通（非遗漏）；广州火车站@11号线暂缓开通**——暂缓站无牌保留原圆（勿当缺数据补录，2026-10-23 误补 11|14 已撤销）。
- 显示线号 = 裸线号（`1`/`10`/`22`/`APM`），**广佛线 = `GF`**（用户指定）；序号两位补零。
- CSV 有而图上无走廊的线（佛山2号线=F2）不生成牌不入核对域。

### 画法（官图 gz-map-2025b 编号版，用户 4 张用例截图定稿；2026-10-23 二轮修正=等宽+缩小+避让）
- 牌 = 横向圆角胶囊：白底 + 黑字(5.5px/全网 6.0px/单线 bold) + 边框=本线色 1.0px + 内部本线色竖分隔线；牌高 9/10（2026-10-23 五轮再缩，PADX1.8/SEPW2.6/组缝1.0）。**APM 专用 4.1px/4.5px 小字号 + `textLength` 压缩**（四轮：APM 牌与数字牌同大）。
- **定宽格等宽**（用户：1位与2位数字线号的牌必须一样大）：线号格=max(两位数字宽, GF宽)，序号格=两位数字宽；牌宽=2×PADX(2.0)+格宽+SEPW(3.0)，取 max(格宽, 实测文本宽) 后向上 0.5 取整——**文本宽度必须字体实测**（msyhbd.ttc getlength，APM 估 13 实 17；CSV 支线序号 01-1 宽于两位格）。全网 398 牌**全部**统一 20.5×9（五轮：APM=4.1px、支线序号 01-1=0.75 档小字号 4.1px，均 `textLength/spacingAndGlyphs` 压入标准格——超宽文本不取 max、靠压缩，任何牌不得因内容加宽）。
- **多线组外描边圈=沿胶囊边缘的包络**（官图用例，2026-10-23 四轮定技法/五轮收紧）：底图换乘胶囊同款**双描边技法**——组内每个胶囊矩形先描粗黑边(stroke 2×(pad+0.7))再描细白边(2×pad)，相邻胶囊描边自动融合成连续外轮廓（黑边0.7px+白衬 pad=1.2，五轮 2.5→1.2 贴紧胶囊），牌画最上层；发射序=全组黑pass→全组白pass→全部牌。外圈冲突解析=先沿走廊推让邻站单牌(触线保持)→逐档收缩pad(0.9/0.6/0.4)；站名避让障碍=轮廓外缘矩形(多线站,含pad+RIM)或牌矩形(单线站)。
- **站名避让**（编号版专属）：牌压名的标签组沿"远离最近相犯牌"方向外推（0.5px 步进 ×8 方位，步程上限 24px——品字外圈宽~51px，16px 逃不出去=天河公园卡死先例），校验=牌净距≥1.0+走廊净距≥1.0+邻标净距≥0.3；**净距判据双陷阱**——①rects_overlap(pad) 是"两轴侵入都>gap"才报，3.5×0.9 擦边全漏（首轮 17 处假绿根因）；②_gap 曾把 r2 x1 误写成 r2[0]+r2[3]（高），二~六轮所有净距判定被扭曲（广州东站标签 0.4px 擦边漏推根因）——净距必须用真 _gap() 且矩形下标自检；兜底链=放标签互斥→放走廊（牌不压名优先），全图 0 放宽 0 无解。

### 排布（按交汇线数；2026-10-23 九轮终稿=用户全部裁定收敛）
| 线数 | 模式（优先级序） | 实例 |
|---|---|---|
| 1 | S 单牌骑线（牌心=本线钉） | 246 站 |
| 2 | **V 上下叠**（同列紧排：列x=钉x均值——平行走廊站两线各距~12<半宽10.25+走廊半宽3.5 触线成立）；H=退化兜底 | 64 站（官洲/大学城北） |
| 3 | **P3 T字（上二下一）/ P3D 品字（上一下二）** 三角两朝向按方向匹配择优——**平行走廊站也是三角**（八轮用户： 大学城南=上12/7下4、芳村=上22/11下1；七轮"平行走廊3线=V"系过度推广已废）；V/H=退化兜底 | P3×4+P3D×3 |
| 4 | G4 田字（2×2，列心=列钉x均值） | 1 站（西塱 1/10/22/GF） |

- **⚠️三角两朝向必须显式生成**：旧实现用 max/min 钉y定单牌行——共y钉时 P3/P3D 退化成同一候选，真 T字（单牌行在下）从未被生成（大学城南做不出上12/7下4的根因）；现 P3=单牌行在下、P3D=单牌行在上，成员仅做几何初始化，线-槽配对一律由置换搜索定。
- **槽位与牌解耦（七轮核心）**：全牌等宽 → 每模式槽位做**全排列组合搜索**（≤24置换），按「全触线>规范优先级>方向匹配>最差距离」取最优——弹性网格重写时丢过排列搜索，共钉线左右位被钉序钉死（番禺广场18/22、广州东站3/1 用户连续两报）。
- **方向匹配三分量**：①钉偏移方向；②**走廊出向**（exit_vec=站邻域走廊采样合成向量，**半径必须60**——半径30采不到38pt外的走向段，大学城南4号线南向段在38pt外被算成0）；③线号序tie-break（小号先得上/左槽，东山口1上6下=官图用例口径）。
- **标签三 pass（八~十一轮）+密集档压线约定（十一轮末 用户重申既有约定）**：**fs<7 的密集档小字（底图逐档缩小 6/5/4.2，APM夹缝等实在显示不下处）允许压线**——走廊净距豁免（不推让、可贴牌），但必须用小字号；7.5px 常规标签强制走廊净距≥1.0。①避让——触发=牌净距<1.0 或（fs≥7 时）走廊净距<1.0，方向=远离最近违规者（牌心或走廊段投影点），兜底链全约束→放标签→放走廊（**末档不做首个接受——约束一放原位秒「合规」=没动，改全角度×全程取走廊净距最大位**），步程上限28px；②对齐——有牌站标签按主偏移轴吸附组心（阈值1pt，含单牌站）；③逼近——标签与自牌组净距>8pt时沿连线贴近至2pt或约束顶住（小字档免走廊约束可压线贴近）。**⚠️走廊段筛选必须精确距离判定**——中点±70预筛漏掉中点在远处的长线段=标签被推上走廊的根因（广州火车站/嘉禾望岗两报）。十一轮曾把 APM 九站统一 7.5px=违反约定（用户打脸撤销），恢复底图字号：夹缝四站（体育中心南/天河南/妇儿中心/花城大道）6px 可压线贴牌（净距1.7pt），其余 7.5px。
- 集中 review 固化在生成器：`layout_violations`（2线须V/3线须P3|P3D/4线须G4，退化须零）。
- **牌内数字纵向居中=墨迹标定（十轮终版）**：`dominant-baseline=central` + **ty=cy−0.02fs**——central 基准在雅黑下系统性偏低 ~0.017em（20x 实测牌内墨迹中心 +0.10pt，两轮用户「数字偏下」根因），−0.02fs 抬升后 20x 仲裁 offset=0.000。**改偏移必须 20x 渲染标定**（2x 量测有 −0.3pt 亚像素抗锯齿系统偏差不可信）；V6 门禁=抽样 3 牌 20x 裁剪精测 |Δ|≤0.15pt，精测窗=文字锚点 ±2.5pt（全牌内窗会把深色线的分隔竖线算进墨迹）。
- **竖线位置自适应（七轮+十一轮末APM反向）**：1位数字线号格=文本+1.9（窄格）；**APM 竖线右移**——线号格=牌宽−边距−分隔区−两位小字序号格（≈9.3），三字母以93%近原生宽渲染（旧压入7.3格=73%重压，十一轮末用户：给APM三个字多点空间）；2位/GF=定宽格；牌外框恒宽不变，宽度在格间调配——支线序号 01-1 压缩量大减（3/7号线均1位线号）。

- **弹性网格**：槽位先取各线钉位（触线天然成立），再按最小不叠间距对称推开；组内两两防叠松弛迭代（`_separate`）。
- 候选（V/H/P3/G4）按「全触线 > 钉向匹配 > 最差距离」择优；同线纵排钉品字放不下时自动退化（嘉禾望岗→品字可解）。

### 门禁（生成器内置 + verify-codes-cards.py）
- G1/G2 牌数恰等（站,线）∩（钉,码）；G3 每牌与本线走廊距离≤走廊半宽3.5（触线，0 失败）；G4 跨站牌不叠（沿走廊推让解冲突，0 残留）；G5 幂等。
- V2 边框线色/V3 内部黑字/V4 文本适配牌宽/V5 牌不压站名(净距≥0.5) = Edge 渲染像素判定，20 卡 100/100。
- ⚠️ 基卡重生成后必须重跑 gen-codes-cards.py（codes 变体从基卡后处理派生）。
