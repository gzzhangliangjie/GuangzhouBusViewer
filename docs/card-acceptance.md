# 单线卡片验收门禁与测试用例

> 沉淀自 1/2 号线卡片全过程（2026-10-18~19），含用户明令"不要再犯"的四条铁律。
> 配套可运行验收：`tools/verify_card.py`（T0 结构门禁）、`tools/verify_card_pixel.py`（T1 像素门禁）、`tests/`（pytest 回归）。
> 制作方法见 `docs/line-card-guide.md`；本文只管"怎么判定能不能交付"。

## 1. 总则

1. **验收必须程序化**。视觉/肉眼只做辅助，通过依据永远是脚本输出（铁律来源：1号线全流程）。
2. **门禁分层**：T0 结构层（毫秒级，改一次跑一次）→ T1 像素层（秒级，交付前必跑）→ T2 交付流程（人工三件事）。全绿才算过。
3. **用户验收过的位置是钉位**，重放标签算法不得漂移（`l2-labels.py` PINNED 表；嘉禾望岗 2026-10-19）。
4. **SVG 改后必换 verify 页 cb 戳**，否则浏览器吃缓存，改了像没改。

## 2. T0 结构门禁（tools/verify_card.py，G1~G9）

用法：`python tools/verify_card.py assets/lines/line-2号线.svg --expect-n 24`

| 门禁 | 判据 | 阈值 | 来源教训 |
|---|---|---|---|
| G1 z序 | 组顺序 走廊→站圆→线路徽标→站名标注 | 严格递增 | 空蓝框/z序铁律 |
| G2 圆在线 | 每站圆到走廊折线距离 | ≤1.5px（铁律3） | 站点必须严格在线上 |
| G3 走廊完整 | 端点邻近聚类(0.5px)后：单连通、游离端点=2 且都在终点圆 12px 内 | 连通段=1 | 路线不中断不多出（铁律4）；终点裁剪 |
| G4 站数 | 站圆数=中文站名数=期望站数 | 全等 | v3 换乘多圆错位连锁 |
| G5 配对 | 每中文名必有英文（同x、基线差 0~12） | 缺一即红 | 结构化站名不缺字 |
| G6 出框 | 标签盒(PIL 实测宽)全在 viewBox 内，左边距 | ≥3px / 左边距≥10 | 英文站名比中文宽（市二宫） |
| G7 净距 | 中文行盒到走廊净距≥9.5；英文行到走廊中线≥4(笔宽3.5+0.5) | 分层 | 嘉禾望岗贴线（2026-10-19） |
| G8 徽标 | 恰好3枚(1全尺寸+2终点60%)，不压标签/走廊 | 无交叠 | 终点徽标避让；广州南站英文行压徽标 |
| G9 归属 | 标签盒(+2px)不得罩住非自站圆 | 无 | 斜线密集段标签漂到邻站（规则8验收） |

## 3. T1 像素门禁（tools/verify_card_pixel.py，P1~P4）

用法：`python tools/verify_card_pixel.py assets/lines/line-2号线.svg`
原理：SVG 内联进包装页（**不走 `<img>`**——file://+img 有加载竞速，灰图根因）→ 无头 Edge 截图 2x → numpy 判定。

| 门禁 | 判据 | 来源教训 |
|---|---|---|
| P1 渲染非空 | 线色像素量 ≥ 走廊弧长×笔画宽×0.7×0.6 | 整页拒渲（ns0: 前缀 / xmlns 手写） |
| P2 逐站墨量 | 每站标签盒内深色像素 ≥ 阈值(按字数缩放) | 站名缺字/空标签 |
| P3 文字不压走廊 | 实心走廊(腐蚀3px+膨胀)膨胀2px 邻域内无文字墨 | 真实渲染字体比估宽更胖 |
| P4 徽标区纯净 | 徽标矩形内无站名深色墨 | 徽标被站名盖住 |

**像素坑（勿重蹈）**：
- 蓝色掩码会被文字 ClearType 亚像素蓝边污染（散点 (61,154,226)/(26,104,190) 特征）——判定前必须形态学腐蚀滤掉；
- pymupdf 不渲 `<line>` 的 CSS 描边，一切栅格验证走浏览器；
- 8765 服务会死，先查服务再怀疑代码。

## 7. 新线路接入门禁的最小步骤

1. 生成/修改卡片后：`python tools/verify_card.py <卡片> --expect-n <站数>` → 9/9；

## 8. 批量生成（tools/build_card.py，2026-10-19）

用法：`python tools/build_card.py [线路名...]`（缺省=除1/2外全部17线）
数据链：metro-data 站序 + gz-tim-2026.svg 几何 + 5700px 渲染图环色 + L1/L2 定稿圆钉池。

流程：选廊(钉评分+相容组并集) → 环色圆归线 → 钉投影/弧长插值补圆 →
弧长序+2-opt 站序修正(钉锁定) → **站序折线走廊(v6直线风格)** → 六规则+规则8标签 →
徽标八向/堆叠/网格避让 → 逐线 G1~G9。多遍构建：过门禁线的站名坐标反哺钉池。

产出 17 线全过 G1~G9（pytest `tests/test_all_cards.py` 参数化 38 用例全绿，
像素层抽查 3/11/广佛/APM 全 4/4）。1号线为旧结构定稿，另见 verify-line1.py。

已知限制（诚实披露，不是门禁项）：
- 站名↔圆位的语义真值靠"钉(换乘站)+站数+最短折线"约束，钉位疑议列表在各线构建警告里
  （密集换乘区个别站可能错位；门禁只保结构正确，不保语义正确）；
- 走廊为站序直连折线（v6 风格），非原图曲线；支线并入主线折线；
- 每线 `钉位疑议` 警告可用"官图放大读标签"逐站核对后加钉重放消除。


## 9. 逐线语义验证（verify_naming.py，2026-10-19 终版）

每张卡的站圆带 `data-nm` 站名标记，验证三层（19/19 全过，含1/2号线定稿卡）：
1. **V1 卡内站序**：`<circle data-nm>` 文档序 == metro-data 真值序（主线+支线整块插入；1号线旧结构豁免，由 verify-line1.py 历史把关）；
2. **V2 换乘互检**：同名站跨线坐标多数派仲裁（容差70px；合法换乘两线圆位偏移实测至~55px）；
3. **V3 真值钉**：L2 真值24站在各线位置 ≤45px。

方法沉淀：
- **官方站编号是语义锚**（official-stations.json 每站 officialSeq+官图坐标）；svg2off 锚站 47 个中 27 个经验证为 Tim 精确坐标（15/20 与真值<10px），并入钉池后 11/8 号线全线复活；
- **钉锁不到圆(换乘大站常缺)必须在钉位合成圆**，否则 2-opt 会塞入远处错圆（嘉禾望岗/广州火车站 1200px 级错位根因）；
- **多数派仲裁闭环**（fix_naming.py）：不一致站→多数派坐标注入→重建少数派线→复验，2轮收敛；
- **站序保真优先于几何最优**：有钉线禁用 2-opt 几何重排（重排破坏真值顺序）；
- P4 像素门禁必须排除徽标自身底色（深色线色如8号线teal会被<150深色阈值误伤）。

### 1号线定稿要点（复用于他线）
- 可信钉=几何验证源（L2真值24+L1卡16，两对互换已修正）；
- 走廊=本线色组几何的站链路径+终点延伸+共线去重；
- 终点版式=文字轴向居中+徽标三点一线；
- 门禁 10/10 + 像素 4/4 + 语义 ✓ 为放行标准。

### 斜线站文字策略（规则9 终版，2026-10-19 二号线用户定稿，45° 为界）

**角度分类**（取最近走廊段方向 ux,uy 归一化后）：
| 段斜率（与水平夹角） | 布局 | 说明 |
|---|---|---|
| < 45°（\|ux\|>\|uy\|，偏水平） | 上下布局 | 与横线站同款：文字在圆点上方/下方，x 居中对齐圆点 |
| > 45°（\|ux\|<\|uy\|，偏竖直） | 左右布局 | 与竖线站同款：文字在圆点左/右侧，与圆心同高、水平延伸 |
| ≈ 45°（±3°，0.74<\|ux\|且0.74<\|uy\|） | 法线方向放置 | 规则8：盒中心=圆心+法向×(G+半投影)，优先线左侧(nx<0)，净距不足换法右 |

- 判定源：站圆最近段的归一化方向分量（放置器 horiz/diag 字段）；
- 净距校验（zh≥8.7/en≥4.2 到走廊中线）不达标时依次换侧/换布局，仍不行用规则7外推兜底——**"哪种不需要微调就用哪种"**；
- 二号线 9 站验证：石壁、南洲-昌岗段（含东晓南/江泰路）、白云文化广场-黄边段（含萧岗/江夏）皆正 45°，法向放置全部一次放正（南洲因净距取法右，其余法左）。

**演变记录**（避免再绕弯）：初版法向（好）→ 水平居中上下放（斜线上下堆叠会挤邻站区间，弃）→ 侧放同高（丢失法向对齐感，弃）→ **终版回归法向 + 45° 分类边界**。

## 12. 二号线定稿 v2 全过程（2026-10-19 验收通过）

> 起点：1号线标准化的规则 9（45° 为界）回应用到二号线斜线站；终点：用户逐站验收通过。

### 最终版式（南段斜线四站）
石壁/南洲-昌岗段/白云文化广场-黄边段共 9 站全部**法向侧阶梯**（南段法右、北段法左）：
- 纯法向偏移（中心 = 圆心 + 法向×(G+半投影)），**不做沿线滑动**——滑动会破坏斜向布局感；
- 同侧阶梯天然错高（≈站距×sin45°），**穿插混淆为零**——异侧对（一上一下）必同高，是混淆根源；
- 均匀节奏跟随真实站距，**不人为拉扯**——间距不一致是地图事实（如江泰路-昌岗 102px），标签间距与之成正比即视觉均匀。

### 迭代路径（三轮教训）
| 轮次 | 方案 | 用户反馈 | 结论 |
|---|---|---|---|
| v1 | 法向（规则8 原始） | "跟参考图不一致" | 需参照参考图 |
| v2 | 水平居中上下放 | "全变成竖向对齐了 不合理 会跟其他站点打架" | 上下堆叠在斜线必挤邻站 |
| v3 | 侧放同高（左右） | "的确这些45度线上的站点 按照斜线法线方向放置好点" | 需斜向感 |
| **v4** | **法向同侧阶梯** | **"很好 2号线通过"** | **同侧=不穿插+斜向感+错高均匀** |

### 根本性教训：不要发明算法，按源图数据直取

| 错误做法 | 正确做法 | 教训 |

### 分叉线处理流程（已验证，复用于他线）

1. **走廊**：CSS类提取（st48 等），图例段（x<300）过滤
2. **站圆**：同色环带匹配 + 走廊6px邻近，**不合成多余圆**
3. **分线**：主线（metro-data stations）+ 支线（branches），分别处理
4. **站位**：
   a. 钉站（可信钉）→ 物理最近圆（距离<60）
   b. 主线余站 → 按弧长比例配余圆（不足的走廊插值）
   c. 支线站 → 支线圆（x>1700 且 y<1000 区域）+ 端点外推
5. **走廊连通**：分叉处主竖线段**在分叉y劈开**（桥的端点才能接上）

### 终点三件套规则（圆→文字→徽标，走廊延长线方向）

| 位置 | 距圆心 | 说明 |
|---|---|---|
| 站圆 | 0 | r=4.5, 白底线色描边2px |
| 中文文字 | ~28px | 轴向居中（同x或沿延长线） |
| 英文文字 | 中文y+8 | **x必须=中文x**（配对门禁±0.3） |
| 终点徽标 | ~55px | 沿走廊末端方向（用make_badge，勿手写transform） |

### 拐角/斜线站标签

| 位置类型 | 布局 | 注意 |
|---|---|---|
| 45°斜线站 | 法向侧（规则9） | 英文行放在中文下方时净距可能不够→中英文同时推远 |
| 走廊拐角站 | 上方左侧（远离连接段） | 连接段（短斜线）会侵蚀净距，标签左移避开 |
| 水平走廊站 | 上方居中 | 中文基线 = 走廊y - 14, 英文 = 走廊y - 6 |

### 徽标操作铁律

1. **手动改transform必带居中修正**：`translate(x y) scale(0.6) translate(-x -y)`，缺 `translate(-x -y)` 导致位置飞出
2. **重建用make_badge**，不要手动拼transform
3. 徽标→文字最小净距 8px（盒边到盒边）

### G10 门禁补丁（本会话新增）

- **堆叠检查**：间距 < 3px = 堆叠 = 不合格（之前只查 >110 不查 <3）
- **链感知**：多链（主线+支线）各自量距，分叉边界不算超距
- **中位数上限**：cap = max(2.5×min(中位,80), 110)，防中位数膨胀

### 根本性发现：Tim 矢量图自带线路分组体系

`assets/gz-tim-2026.svg`（=Wikimedia「Guangzhou-Foshan Metro Diagram by Tim」，md5 0027d904）内部结构：

1. 走廊 = 按组 id 提取 line + 圆角 path（path 用 build_card.sample_d 状态机，正则解析 d 数字必炸）
2. 站位真值表 = 原图站圆位置（换乘黑圆/本线色圆）× 官方案号序严格对位；颜色约束（换乘站→黑圆）可反推错位
3. 无圆站（中山八/广州火车站/夏园/如意坊/东湖等）在走廊上插值，标「补」
4. 圆角 path 并入走廊段（否则 G3 断连）；终点=走廊端点时天然免裁剪

## 15. 晚间问题复盘与验收页规范（2026-10-19 深夜）

### 15.1 验收页必须原始尺寸渲染（用户明令）

**事故**：verify 页把 `<img>` 压到 `width=400`，30+ 站的长条卡（5号线1710×486、6号线1320×504）被压成小图，站名根本看不清，用户投诉"图太小了"。

**规则（写入建卡模板）**：验收页 HTML 固定写法：
```html
<img src="line-X号线.svg?cb=时间戳" width="viewBox原始宽" height="viewBox原始高">
```
禁止再用 400px 缩略；?cb= 时间戳防缓存（SVG 改后必换戳）。
